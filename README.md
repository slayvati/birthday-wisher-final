Birthday Wisher----------------------------------------------------------------------------------------

A simple birthday reminder web app built using Flask, SQLite, HTML, CSS, and JavaScript.

Features:
- Shows birthdays for the current day
- Displays images and birthday wishes
- Uses SQL database connectivity

How to Run---------------------------------------------------------------------------------------------

1. Install Python

2. Install Flask:
   pip install flask
   
3. Run:
   python create_db.py

4. Then run:
   python app.py

5. Open:
   http://127.0.0.1:5000
